# Communications Room

This room teaches the Resonant Agent how to add or repair communication
interfaces without breaking continuity, privacy, or operator control.

The shipped web interface already stores its readable transcript, isolates each
conversation's Pi session, and maintains the local External Brain. Read
`SESSION-CONTINUITY.md` before building a connector, permanent resident
gateway, second interface, or restart supervisor. It defines the exact-session
pin and the proof required before claiming that an agent will return with its
continuity intact.

New external transports remain disabled until the operator chooses to configure
them. Never store credentials in this room, the harness, memory, chat logs, or a
session pin.
